# DARS Location Bot

## Overview
DARS Location Bot is a Telegram-based automation system developed to simplify and improve the collection and submission of location information for the Documents Authentication and Registration Service (DARS).

The bot allows authorized users to submit location details through an interactive Telegram interface. Submitted information is automatically forwarded to a designated Telegram group for centralized communication and management.

## Key Features
- **Location Submission:** Collects region, zone, district, and kebele information.
- **Automated Messaging:** Automatically forwards submitted location information to a designated Telegram group.
- **Duplicate Prevention:** Prevents repeated submissions of identical location information.
- **Admin Control:** Provides administrative controls for managing and confirming submissions.
- **Working Hours Management:** Restricts user access according to configured working hours.
- **User-Friendly Interface:** Provides interactive Telegram buttons for easy navigation and submission.
- **Database Integration:** Uses SQLite to store and manage submission records.
